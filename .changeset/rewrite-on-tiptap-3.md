Rewrite notra-editor from scratch on Tiptap 3, shadcn/ui and Tailwind CSS 4: a block-based editor with slash commands, a bubble menu, a block handle with drag and drop, tables, images, toggle blocks, Markdown support, themes and i18n. This release replaces the previous implementation (0.8.x) and its API; see the README to get started.
